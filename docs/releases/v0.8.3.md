English translation of **Tengai Makyou II: Manji Maru** for **Nintendo GameCube**, supporting the Japanese disc **GT2J18, revision 0**.

v0.8.3 adds English password entry and includes the cumulative translation, subtitle and layout fixes since v0.8.2. It packages tested internal build **0.1.2615**. **Translation remains in progress.**

### Apply

Use the current [Retro Trans Tools Windows release](https://github.com/retro-trans/retro-trans-tools/releases/latest). Automatic selects the matching full or upgrade route and verifies the complete output.

For manual installation, use **Apply xdelta** with the matching patch.

### What changed since v0.8.2

- Add an English A-Z password keyboard for both puzzles, with Space, Delete, Left, Right and Done. Support 20 characters and accept answers regardless of capitalization or spaces. Translate all ten prompt variants and check the corresponding clues.
- Translate the full-party reward refusal and its shared Yes label, plus all battle ally-target names and field recipient names/free-slot counts.
- Complete and widen the travel destination picker for full English names. Translate related travel, wind, escape and location-refusal messages.
- Correct recurring dialogue gaps around highlighted names and other reported prose, and translate the reported grandmother and ninja conversations.
- Keep both lines of equipment descriptions above the shop border and check long descriptions, scrolling, purchases, sales and reopening.
- Add subtitles to the orchid finishing clips and Kikugoro's retreat voice.

### What's Included

- **UI/navigation changes for English text:** roomier labels and descriptions, two-column lists, clearer action buttons, full character names and improved placement. Consistent action → user → item flows; Give / Exchange adds a recipient and destination slot, with clearer Back navigation and a persistent selected-user highlight.
- **Added Random Encounters option:** **Options → Random Encounters → None / Less / Default / More**, adjusting random walking encounters while retaining bosses and scripted battles.
- English dialogue, menus, item/equipment help, Scroll/Arts descriptions, battle messages, subtitles and field-use messages developed so far; further translation/proofreading remains.
- Normal-resolution Balsamiq Sans Regular, consistent **Arts** labels and eight English castle banners preserving the original frames/colors.
- **Direct Control / AI Control** clarifies the original game's existing Strategy control setting; we did not add party-control functionality.

### Validation and testing status

The public release has exactly the game bytes of tested internal build 0.1.2615. Native checks cover both password modes, all ten prompts, all 31 keys in four directions, correct and incorrect answers, editing, capacity limits, result delivery and window cleanup. Related reward confirmations, installed clues, travel results, party names and shop behavior were checked during their respective fixes.

Both canonical patches are fully decoded from their exact source images and compared with the complete target size and SHA-256. Live **Retro Trans Tools 0.5.23 Automatic** passed from the Japanese original and public English **v0.8.0, v0.8.1 and v0.8.2**. Fresh catalog and patch downloads produced the exact v0.8.3 ISO, recognized it as current, preserved all inputs and rejected overwriting existing files. Explicit v0.8.3 and Latest routes select the correct updates, and Next version only retains the original version sequence. [Automatic evidence](https://github.com/retro-trans/Tengai-Makyou-II/blob/main/docs/AUTOMATIC-0.8.3.json).

The published **Windows v0.5.23 app** passed original **RVZ → Automatic → RVZ** with a fresh app cache and live downloads. Independent extraction reproduced the complete v0.8.3 ISO hash. These are installation tests. Game playback and physical hardware were not exercised. [RVZ evidence](https://github.com/retro-trans/Tengai-Makyou-II/blob/main/docs/RVZ-0.8.3.json). [Catalog refresh](https://github.com/retro-trans/retro-trans-tools/actions/runs/43404204018).

This is an in-progress translation. Japanese text may remain. The new password and reward code, UI allocations and compressed room changes have passed native checks, but natural access to these scenes in Dolphin and physical GameCube play remain untested. A full playthrough, transition timing under natural memory pressure and memory-card write/restart/reload have not been validated. Earlier opening-warning source uncertainty remains documented.

Hardware-sensitive changes since v0.8.2 include rewritten password editing/navigation/comparison, English answer records and a new input-buffer format inside the original 30-byte buffer. Password prompt backing requests 1,968 extra bytes and the reward refusal requests 2,880 extra bytes before allocator rounding. Travel menus can add up to 4,224 live bytes. Scoped display/parser branches and subtitle records change, and compressed MAP/header/FST metadata changes. These can affect heap pressure, fragmentation, timing and console execution. Native checks and patch verification do not establish real-hardware compatibility. Detailed evidence and limits appear in the testing notes.

[Testing notes](https://github.com/retro-trans/Tengai-Makyou-II/blob/main/docs/TESTING.md).
