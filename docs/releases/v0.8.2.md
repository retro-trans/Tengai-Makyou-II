English translation of **Tengai Makyou II: Manji Maru** for **Nintendo GameCube**, supporting the original Japanese disc **GT2J18, revision 0**.

v0.8.2 fixes dialogue spacing and wrapping, translates more field item actions and no-effect results, and translates postbattle item rewards. It packages tested internal build **0.1.2552**. **Translation remains in progress; Japanese text may remain.**

### Apply

Use [Retro Trans Tools 0.5.21 or later for Windows](https://github.com/retro-trans/retro-trans-tools/releases/latest): **Automatic → Refresh catalog → select your original Japanese or public English image → 0.8.2 / Latest → choose a new output → Patch**. The app selects the matching patch route and verifies the complete output. English v0.8.0 can upgrade through v0.8.1 automatically.

For manual installation, use **Apply xdelta** with the patch matching your input:

| Your source image | Patch |

| Exact English v0.8.1 image from this project | `Tengai-Makyou-II-English-v0.8.1-to-v0.8.2.xdelta` |

**RVZ:** Windows 0.5.21 supports RVZ input and output directly. Approve ISO extraction, select the release, then choose **RVZ** output or **Original format** for ISO output. Original inputs are retained and RVZ output is verified against the complete patched ISO. A converter is bundled; Windows 10 1903 or later, x64, and the current [Microsoft Visual C++ v14 x64 runtime](https://aka.ms/vc14/vc_redist.x64.exe) are required. Mac/Android direct RVZ conversion is not included; convert to ISO first. RVZ compression hashes vary; compatible images are identified by their expanded ISO hashes below.

Keep verification enabled. Do not apply the v0.8.1 upgrade patch to a different English test build. **Cold-boot the new image and load an in-game memory-card save; emulator states can restore old code/text.** No complete game image is distributed.

### What's Changed

- **Dialogue layout:** remove unwanted wide spaces around colored names and rewrap the reported conversations, including the festival, inn, village and Hermit Kasaiwa castle dialogue. Preserve wording, name colors and original page turns.
- **Field item messages:** translate the shared mouth action, complete actor/item/recipient names and nested healing result; add the Ear Pick of Love action and “But it had no effect.” Related instruments, ring, mirror, bell and staff actions, plus the smelly-hands outcome, are translated too. Original item effects and consumption stay intact.
- **Battle rewards:** translate native one-, two- and three-item result messages and English item/equipment names. Expand a smaller reused result window before parsing so the English rewards fit.
- Retain the v0.8.1 healing-message freeze fix and three opening subtitle additions. Original movies and audio remain byte-identical; no video re-encoding.
- Full original-source patch and a small upgrade from English v0.8.1, with Automatic metadata, checksums and complete round-trip verification.

### What's Included

- **UI/navigation changes for English text:** roomier labels and descriptions, two-column lists, clearer action buttons, full character names and improved placement. Consistent action → user → item flows; Give / Exchange adds a recipient and destination slot, with clearer Back navigation and a persistent selected-user highlight.
- **Added Random Encounters option:** **Options → Random Encounters → None / Less / Default / More**, adjusting random walking encounters while retaining bosses and scripted battles.
- English dialogue, menus, item/equipment help, Scroll/Arts descriptions, battle messages, subtitles and field-use messages developed so far; further translation/proofreading remains.
- Normal-resolution Balsamiq Sans Regular, consistent **Arts** labels and eight English castle banners preserving the original frames/colors.
- **Direct Control / AI Control** clarifies the original game's existing Strategy control setting; we did not add party-control functionality.
