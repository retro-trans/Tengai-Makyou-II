English translation of **Tengai Makyou II: Manji Maru** for **Nintendo GameCube**, supporting the original Japanese disc **GT2J18, revision 0**.

v0.8.1 fixes a field-healing message freeze reported with Buckwheat Dumpling and adds three missing opening subtitle cues before the mother's first “Manjimaru…” line. It packages tested internal build **0.1.2518**. **Translation remains in progress; Japanese text may remain.**

### Apply

Use [Retro Trans Tools 0.5.21 or later for Windows](https://github.com/retro-trans/retro-trans-tools/releases/latest): **Automatic → Refresh catalog → select your Japanese original or English v0.8.0 image → 0.8.1 / Latest → choose a new output → Patch**. The app selects the matching patch and verifies the complete output.

For manual installation, use **Apply xdelta** and the patch matching your input:

| Your source image | Patch |
| --- | --- |
| Original Japanese GameCube ISO, GT2J18 revision 0 | `Tengai-Makyou-II-English-v0.8.1.xdelta` |
| Exact English v0.8.0 image from this project | `Tengai-Makyou-II-English-v0.8.0-to-v0.8.1.xdelta` |

**RVZ:** Windows 0.5.21 supports RVZ input and output directly. Approve ISO extraction, select the release, then choose **RVZ** output or **Original format** for ISO output. The original RVZ and extracted ISO are retained; RVZ output is verified against the complete patched ISO. A converter is bundled. Windows 10 1903 or later, x64, and the current [Microsoft Visual C++ v14 x64 runtime](https://aka.ms/vc14/vc_redist.x64.exe) are required. Mac/Android direct RVZ conversion is not included; convert to ISO first on those platforms. RVZ compression hashes vary; the ISO hashes below identify compatible images.

Keep verification enabled. Do not apply the upgrade patch to a Japanese original or a different English test build. **Cold boot the new image and load an in-game memory-card save; older emulator save states retain old code.** Start a New Game to see the repaired opening naturally. No complete game image is distributed.

### What's Changed

- **Field healing freeze:** reserve enough text backing in the actual Item-use message producer before it inserts the English HP-recovery result. The public 0.8.0 executable reproduced a native parser stall; the fix preserves healing calculations, item consumption, RNG and visual layout. This addresses the shared message path; the player's exact lakeside save has not been replayed.
- **Missing opening subtitles:** add Manjimaru's request for another serving and the outside caller's question/warning before the mother's existing first line. All 658 older subtitle cues retain their wording, timing and placement. Original movie and audio files remain byte-identical; no video re-encoding.
- Full original-source patch and a small upgrade from English 0.8.0, with Automatic metadata, checksums and complete round-trip verification.

### What's Included

- **UI/navigation changes for English text:** roomier labels and descriptions, two-column lists, clearer action buttons, full character names and improved placement. Consistent action → user → item flows; Give / Exchange adds a recipient and destination slot, with clearer Back navigation and a persistent selected-user highlight.
- **Added Random Encounters option:** **Options → Random Encounters → None / Less / Default / More**, adjusting random walking encounters while retaining bosses and scripted battles.
- English dialogue, menus, item/equipment help, Scroll/Arts descriptions, battle messages, subtitles and field-use messages developed so far; further translation/proofreading remains.
- Normal-resolution Balsamiq Sans Regular, consistent **Arts** labels and eight English castle banners preserving the original frames/colors.
- **Direct Control / AI Control** clarifies the original game's existing Strategy control setting; we did not add party-control functionality.

### Validation and testing status

- 72 actual native Item menu/effect/nested-message cases and 12 repeated use/reveal/free cycles pass, including related healing items, HP limits, exact one-item consumption and cleanup. Actual Store construction, Buy/Sell/funds/Back/reopening and captured allocation-pressure checks pass.
- All 661 subtitle records and 2,360 native boundary checks, plus 45 additional new-cue guard/edge checks, pass. A muted isolated Dolphin New Game replay shows all new cues, the unchanged mother cue and a cleared subtitle overlay after returning to gameplay. The healing path was rechecked on this exact final build.
- Both patch routes pass complete ISO verification using Retro Trans Tools 0.5.21 Apply xdelta. Canonical release packaging independently verifies both round trips. Live Automatic routing/download verification is recorded after publication.

**Known limits:** the final words of the shouted warning are less clear in recognition and use a context-based rendering. A full playthrough and physical GameCube operation remain unverified. The exact reported lakeside save, natural healing-dialogue controller timing and actual memory-card write/restart/reload remain untested. Native/Dolphin checks are not real-hardware validation.

**Hardware-sensitive changes since 0.8.0:** healing-message backing grows by 2,952 live bytes, which may affect heap headroom/fragmentation/timing. New immutable subtitle data adds 232 executable bytes within existing reserved padding. No new static reservation or scene reduction: arena low remains `0x80389000`, scene capacity 1,060,704 bytes, general heap 4,718,592 bytes, private spare 1,736 bytes. Inherited executable/font/menu/subtitle/banner risks persist. [Detailed testing notes](https://github.com/retro-trans/Tengai-Makyou-II/blob/main/docs/TESTING.md).
