English translation patch for the **Japanese GameCube version of Tengai Makyou II: Manji Maru**.

This is the first public release here, based on verified internal checkpoint 0.1.2503. Translation remains in progress; Japanese text may remain. The release number is not a measured completion percentage.

### Install

Use the current [Retro Trans Tools Windows release](https://github.com/retro-trans/retro-trans-tools/releases/latest): **Automatic → Refresh catalog → original Japanese ISO → 0.8.0 / Latest → new output ISO → Patch**. The app downloads and verifies the patch automatically. Convert your own RVZ dump back to an unmodified ISO first, if applicable.

For manual use, download `Tengai-Makyou-II-English-v0.8.0.xdelta` and use **Apply xdelta**. No game image is included. Read the [README](https://github.com/retro-trans/Tengai-Makyou-II#readme) for the exact supported original and installation details.

### Included

- English dialogue/UI, item and equipment help, Scroll/Arts descriptions, battle messages, subtitles, and eight castle banners developed so far.
- Normal Balsamiq lettering, unified **Arts** command labels, **Direct Control / AI Control**, and clearer Scroll action buttons.
- Action → User → Item flows; Give / Exchange adds recipient and destination selection. Back navigation and persistent chosen-user highlighting are retained.
- Full English shop character names, raised shop metadata, the reviewed Battle Item description bank, and full-name English Scroll/Art field-use refusal messages.
- Original opening movie files remain unchanged; movies were not reencoded.

### Verification and limits

The full patch was decoded and matched byte-for-byte to the verified internal ISO. The canonical manifest, validation report and checksums are attached for Retro Trans Tools Automatic. The live 0.5.20 Automatic backend passed public-catalog refresh, original recognition, empty-cache download, application and complete output verification; all three version selectors reach 0.8.0. [Verification record](https://github.com/retro-trans/Tengai-Makyou-II/blob/main/docs/AUTOMATIC-0.8.0.json).

Native routine, text, menu and captured allocation-pressure checks passed. **No physical-hardware or full-playthrough validation.** Executable/font/menu/subtitle/banner changes inherit runtime and memory risks: final scene capacity is 1,060,704 bytes, and physical GPU/cache behavior, natural transitions, actual memory-card write/restart/reload and long-session stability remain unverified. Public packaging changes no game bytes. [Detailed testing notes](https://github.com/retro-trans/Tengai-Makyou-II/blob/main/docs/TESTING.md).
