English translation of **Tengai Makyou II: Manji Maru** for **Nintendo GameCube**, supporting the original Japanese disc **GT2J18, revision 0**.

v0.8.0 brings together the English translation, menu and navigation improvements, the new random encounter setting, and translated castle banners developed so far. This is the first public release here, based on verified internal checkpoint 0.1.2503. **Translation remains in progress; Japanese text may remain.**

### Apply

Use [Retro Trans Tools](https://github.com/retro-trans/retro-trans-tools/releases/latest): open **Automatic**, click **Refresh catalog**, select your original Japanese ISO, choose **0.8.0** or **Latest**, and save to a new output ISO. The app downloads the patch and verifies the original and completed image.

For manual patching, use **Apply xdelta** in Retro Trans Tools, or apply the patch with xdelta3. You need your own unmodified Japanese disc image.

| Your source image | Patch |
| --- | --- |
| Original Japanese GameCube ISO, GT2J18 revision 0 | `Tengai-Makyou-II-English-v0.8.0.xdelta` |

**RVZ support:** the **Retro Trans Tools 0.5.21 Windows test build** can accept your original RVZ directly in **Automatic**. Approve ISO extraction, select **0.8.0** or **Latest**, then choose **RVZ** output or **Original format** for ISO output and click **Patch**. It keeps your original RVZ and the extracted ISO, verifies the complete patched ISO, and verifies RVZ output by extracting it again and comparing the complete ISO hash. The converter is bundled; a separate Dolphin installation is unnecessary for this workflow.

**Availability:** 0.5.21 is currently a local test build and has not been publicly released. The current public **0.5.20** download requires you to convert RVZ to ISO in Dolphin first, then follow the ISO instructions above. You can convert the patched ISO back to RVZ in Dolphin afterward. Renaming an RVZ does not convert it.

Both workflows use the same v0.8.0 patch and the ISO hashes below. RVZ file hashes vary with compression settings; verification uses the expanded ISO. Other editions and modified images are unsupported; this release provides a full patch from the original, rather than upgrades from earlier local test builds. Keep checksum verification enabled.

For example:

```text
xdelta3 -d -s "Tengai Makyou II - Manji Maru (Japan).iso" Tengai-Makyou-II-English-v0.8.0.xdelta "Tengai Makyou II English v0.8.0.iso"
```

**Cold boot the patched image and load an in-game memory-card save.** Older emulator save states can retain previous code or graphics.

### What's Included

- **UI and navigation improvements for English text.** Menus have been adjusted to make them easier to read and navigate than the original: roomier English labels and descriptions, two-column lists, clearer action buttons, full character names, and improved text placement. Item, equipment and scroll menus follow a consistent action → user → item flow. Give / Exchange then selects a recipient and destination slot. Back navigation and a persistent chosen-user highlight help you keep track of the current character.
- **New Random Encounters option.** In **Options → Random Encounters**, choose **None / Less / Default / More**. None disables random walking encounters; Less reduces encounter checks; Default retains the original behavior; More increases encounter checks. Bosses and scripted battles remain intact.
- **Clearer labels for the existing Strategy control setting.** The original game's manual/automatic party control is labeled **Direct Control / AI Control** in English. We clarified the wording and text layout; this is not a new gameplay feature.
- **English translation throughout the work completed so far.** Dialogue, menus, item and equipment help, Scroll/Arts descriptions, battle messages, subtitles, and full-name field-use refusal messages are included. Further translation and proofreading are still needed.
- **Clearer English lettering and command names.** Normal-resolution Balsamiq Sans Regular text, consistent **Arts** command labels, clearer Scroll action buttons, and improved shop information.
- **Eight English castle title banners.** Translated titles retain the original decorative frames and color themes. Opening movie files remain original; movies have not been reencoded.

### Validation and testing status

The full patch was decoded from the exact original ISO and verified against the complete target size and SHA-256 hash. All uploaded patch and metadata assets matched their local sizes and hashes. The published **Retro Trans Tools 0.5.20 Automatic backend** passed live catalog refresh, original-image recognition, empty-cache download, patch application, and complete output verification. Latest, Next version only, and the explicit 0.8.0 selection all reach this release. [Automatic verification record](https://github.com/retro-trans/Tengai-Makyou-II/blob/main/docs/AUTOMATIC-0.8.0.json).

Native checks covered text rendering and bounds, menu navigation and transfers, Strategy control choices, actual shop construction and reopening, and captured allocation-pressure models. The Random Encounters implementation has native checks for all four modes, the original default behavior, separate forced battles, and save-record/settings handling. Encounter frequency remains subject to the game's random outcomes and cooldowns; Less and More are not exact short-walk fight-count guarantees.

The packaged **0.5.21 Windows RVZ test build** also passed original RVZ input, a live Automatic patch download, RVZ output, and independent extraction back to the exact English v0.8.0 ISO. Original preservation, existing-output refusal and already-current recognition passed. These are conversion and patch-verification checks, without emulator gameplay or real-hardware testing. [RVZ verification record](https://github.com/retro-trans/Tengai-Makyou-II/blob/main/docs/RVZ-0.8.0.json).

**A complete playthrough and physical GameCube operation remain unverified.** Real rendering/cache behavior, natural scene transitions, actual memory-card write/restart/reload, and long-session stability need further testing. The patch inherits executable, font, menu, subtitle and banner changes with runtime and memory risks; the final scene arena is 1,060,704 bytes. Automated checks do not replace gameplay or real-hardware validation. [Detailed testing notes](https://github.com/retro-trans/Tengai-Makyou-II/blob/main/docs/TESTING.md).

Public version 0.8.0 is byte-identical to internal build 0.1.2503. The release number is not a measured translation-completion percentage.
